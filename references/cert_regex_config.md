# 证书编号正则速查表

本文档是 `ocr_common.py` 中 `CERT_TYPES` 字典的说明。新增证书类型时，同步改两处：**字典加一项 + 本文档加一行**。

## 默认五类

| 类型 key | 类型名 | 文件名提取正则 `file_re` | OCR 内页提取正则 `ocr_re` | 空查册标识 `empty_mark` |
|---------|-------|------------------------|--------------------------|------------------------|
| `realestate` | 不动产权证 | `不动产权第\s*(\d{5,7})\s*号` | `不动产权第\s*(\d{6,7})` | 名下无不动产 / 无不动产 / 名下无房产 |
| `patent` | 专利证书 | `(ZL\s*[\d\s\.]+)` | `专利号[：:]\s*(ZL[\d\s\.]*)` | 无专利 / 名下无专利 |
| `trademark` | 商标注册证 | `第\s*(\d{7,10})\s*号` | `注册号[：:]\s*第?\s*(\d{7,10})\s*号?` | 无商标 / 名下无商标 |
| `business_license` | 营业执照 | `([0-9A-HJ-NP-RTUWXY]{18})` | `统一社会信用代码[：:]\s*([0-9A-HJ-NP-RTUWXY]{18})` | 未查询到 / 无登记信息 |
| `qualification` | 资质证书 | `编号[：:]?\s*([A-Za-z0-9\-\/]{6,})` | `(?:证书)?编号[：:]\s*([A-Za-z0-9\-\/]{6,})` | 未查询到 / 无相关资质 |

## 正则要点

- **`file_re`** 作用于**文件名**，`ocr_re` 作用于 **OCR 文本**。两者都要有**捕获组**（括号），捕获组内容就是编号。
- 统一社会信用代码用了排除易混淆字符的字符集 `[0-9A-HJ-NP-RTUWXY]`（去掉 I/O/S/V/Z）。
- OCR 常丢前导零、掉末位、把空格识别进编号，因此比对时统一 `normalize_number` 去空格，并启用前缀/后缀容错。

## 新增类型步骤

以新增"采矿许可证"为例：

1. 在 `ocr_common.py` 的 `CERT_TYPES` 字典加一项：

```python
"mining_license": {
    "label": "采矿许可证",
    "file_re": re.compile(r"采矿许可证[：:]?\s*([A-Za-z0-9\-]+)"),
    "ocr_re": re.compile(r"证号[：:]\s*([A-Za-z0-9\-]+)"),
    "empty_mark": ["未查询到", "无采矿权"],
},
```

2. 在本文档表格加一行。

3. 运行脚本时用 `--type mining_license`。

## 陌生证书 recheck 机制

Step1 自动探测模式下，OCR 提取到编号但**匹配不到任何已知类型的正则**时，结果会标「未识别类型」并单独列出。此时应：

1. 打开对应 PDF 人工看编号格式；
2. 确认编号类型和正则；
3. 按上述"新增类型步骤"把类型加进 `CERT_TYPES`；
4. 重跑，同类型即自动识别。
